# Changelog

All notable changes to this project will be documented in this file.

This format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-15

### Added

- Initial project setup with Next.js 16 and TypeScript 5
- Better Auth integration for authentication and session management
- Better SQLite3 database layer with schema migrations
- Task management CRUD operations with Zod validation
- Workspace and team collaboration features
- Tailwind CSS v4 styling with dark mode support
- React Query (TanStack Query) for server state management
- Comprehensive test suite with Jest
- Global error handling and structured logging
- RESTful API routes for tasks, workspaces, and comments
- Type-safe database queries and ORM-like patterns
- Environment configuration with dotenv
- ESLint and Prettier configuration for code quality
